# Dynamic Web Application Hosting Setup (EC2 Style)

Dynamic web application server setup using Node.js HTTP routing, static asset serving, and EC2-style hosting configuration.

## Features & Overview
- Built as part of the **B.Tech 1st Year Web Designing & Full-Stack Development** project series.
- Clean, modular separation of markup, styling, client-side logic, and backend/database schemas.

## Tech Stack
- Node.js, HTML5, CSS3, Vanilla JavaScript

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanshmittal575-cpu/aws-ec2-web-hosting.git
   cd aws-ec2-web-hosting
   ```
1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox).
